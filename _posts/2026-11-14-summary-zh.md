Telegram 小组件中发现了一个严重的远程代码执行（RCE）漏洞，该功能于 2026 年 11 月 9 日随 Bot API 10.4 引入。此漏洞利用客户端沙箱缺陷，允许 JavaScript 在聊天消息中运行。 此 RCE 漏洞极其严重，因为它可能允许攻击者完全控制用户设备，对 Telegram 庞大用户群的安全和隐私构成重大威胁。通过聊天消息执行任意代码的能力，从根本上破坏了平台的基本安全保障。 该漏洞源于 Telegram 客户端沙箱实现中的一个缺陷，未能正确隔离机器人通过 Telegram Widgets 功能嵌入的 HTML 和 CSS 中的 JavaScript。建议用户不要点击不明机器人链接，并暂时不要升级客户端。

telegram · zaihuapd · Nov 13, 16:17

**背景**: Telegram Widgets 是随 Bot API 10.4 引入的功能，旨在通过允许机器人在聊天消息中嵌入 HTML、CSS 和 JavaScript 来实现交互式界面。远程代码执行（RCE）漏洞允许攻击者在目标系统上执行任意代码，通常会导致系统完全被攻陷。
