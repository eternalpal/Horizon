## [Stripe 以超 70 亿美元收购 AI API 聚合平台 OpenRouter](https://openrouter.ai/blog/announcements/openrouter-is-joining-stripe/) ⭐️ 9.0/10

Stripe 已正式收购领先的 AI API 聚合平台 OpenRouter，据报道交易价值超过 70 亿美元。此次收购预示着 AI 基础设施和开发者体验领域将发生重大转变。 此次收购对 AI 生态系统至关重要，因为它将一个关键的 AI API 聚合平台整合到 Stripe 的产品中，有望提升开发者体验并巩固 Stripe 在 AI 领域的战略地位。这还可能影响 AI 模型提供商的竞争方式以及开发者访问多样化 AI 能力的方式。 OpenRouter 的核心价值在于将多个 AI 模型提供商聚合到一个 API 之后，使用户能够根据价格和质量进行选择，从而避免供应商锁定。这种模式还为 AI 模型提供商提供了便捷的收入来源和新客户。

hackernews · rvz · Aug 19, 17:32

**社区讨论**: 社区普遍赞扬了 OpenRouter 的产品及其成功的商业模式，认为它促进了 AI 提供商之间的竞争，使用户和提供商都受益。然而，一些人对收购后 OpenRouter 员工的潜在影响表示担忧，并讨论了“中间人”平台与更开放、基于协议的解决方案相比的长期可行性。
